# 분양분석 글 설계 (초안, 2026-10-23)

주간 접수 단지 가운데 관심이 큰 1~2곳을 골라 「분양분석」 카테고리에 단지별 글을 쓴다. 주간 글이 "언제·어디서"라면 분석 글은 "이 단지는 어떤 곳이고 내가 해당되는가"를 숫자와 출처로 정리한다.

## 1. 어떤 단지를 고르나 (후보 점수 → 사용자가 확정)
| 기준 | 근거 데이터 | 비고 |
|---|---|---|
| 분양가가 주변 실거래가보다 낮음 | 주택형별 분양가 vs 반경 1km·비슷한 면적·최근 1년 실거래 | 차이를 숫자로만 쓴다. "로또"·"시세차익" 같은 말은 쓰지 않는다(절대 규칙 2, 검수 금지어) |
| 핵심지 | 서울 전역, 과천·분당·판교·하남·광명 등 목록(설정 파일) | 목록은 사용자가 고친다 |
| 대단지 | 1,000세대 이상 | |
| 싸게 공급되는 유형 | 공공분양·토지임대부·신혼희망타운·분양가상한제 | 청약홈 상세 항목 |
| 통장 없이 되는 공급 | 무순위·임의공급(수도권) | 거주지·자격 조건을 함께 |

자동으로 점수를 매겨 후보 3곳을 채팅에 올리고, 사용자가 고른 단지만 쓴다.

## 2. 글 구성
1. **한눈에** — 단지 카드 그림(주간 글과 같은 모양) + 일정·공급·주택형별 분양가 표
2. **분양가와 주변 실거래가** — 같은 면적대 최근 1년 거래(단지명·거래월·면적·금액) 표, 3.3㎡당 환산 비교. 거래가 적으면 "비교할 거래 부족"이라고 쓴다
3. **입지** — 위치 지도(반경 500m·1km), 가까운 철도역(직선거리), 초·중·고 가까운 순(직선거리). 배정 학교는 교육청 확인 필요 문구
4. **자격·규제** — 규제지역 여부, 분양가상한제, 공고문에 적힌 전매제한·실거주 의무, 무순위면 신청 자격
5. **대출·자금** — 주택형별 분양가로 디딤돌·보금자리론·중도금 보증 기준에 해당하는지(기준값과 확인일, 출처 링크). "받을 수 있다"가 아니라 "가격 요건에 해당"까지만
6. **일정·체크리스트** — 접수일·발표일·계약일, 공고문 링크
7. 출처·기준일·면책

## 3. 데이터
| 항목 | 출처 | 상태 |
|---|---|---|
| 일정·공급·분양가 | 청약홈 API(지금 수집 중) | 있음 |
| 규제 여부·주택형별 금액·시공사 | 청약홈 API 상세 항목 — 수집기(`crawler/fetch.mjs`)에 추가 | 키로 항목 이름 확인 필요 |
| 주변 실거래가 | 국토교통부 아파트 매매 실거래가 상세 API(공공데이터포털) | **활용신청 필요** |
| 학교 | 브이월드 검색 API(`posts/nearby.mjs`) | 있음(좌표는 저장 안 함) |
| 철도역 | OpenStreetMap 전국 역 목록(`posts/stations.json`, `stations_update.mjs`) | 있음(출처 표기 ODbL) |
| 대출·규제 기준 | `data/policy/loans.md`(공식 출처 조사, 확인일 표기) | 조사 중 |

## 4. 흐름
주간 자동 실행(일요일) → 후보 3곳 채팅 보고 → 사용자 선택 → `posts/analysis.mjs`로 초안(`drafts/{공고번호}_analysis.json`) → 검수(숫자는 수집본·실거래·정책 표에 있는 것만, 금지어) → 채팅 승인 → 「분양분석」 카테고리로 임시저장. 분석 글은 판단이 들어가므로 **자동 저장하지 않는다**(주간 글과 다름).

## 5. 사용자에게 필요한 것
1. 공공데이터포털에서 「국토교통부_아파트 매매 실거래가 상세 자료」 활용신청(기존 키 그대로 쓰면 됨)
2. 로컬 `.env`에 `DATA_GO_KR_KEY=…` 한 줄(GitHub Secrets와 같은 값, 커밋 금지) — 상세 항목 확인·실거래 조회용

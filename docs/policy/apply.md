## 확인 못 한 항목 / 출처 간 차이

1. **청약홈 당첨 조회 가능 기간**(발표 후 며칠간 조회되는지) — 로그인 화면 뒤라 확인 못 함. 글에 쓰지 않음.
2. **청약알리미·당첨 문자 서비스 세부**(신청 방법·발송 시각) — 청약알리미 신청 화면이 로그인 필요, 확인 못 함. 법령(제25조제4항)의 "요청 시 문자 가능"만 씀.
3. **인증서 종류 차이(출처 간 차이)**: 청약신청방법(R2)·로그인 화면(R11)은 카카오 인증서 포함 7종, FAQ "공동인증서가 있어야 하나요?"는 카카오 없이 6종 나열 — FAQ가 갱신 전으로 보고 R2·R11 기준(7종)을 씀.
4. **무순위 R1 표의 "청약홈(의무) 2회·1회"**: 제19조제6항 "횟수까지는 청약홈 의뢰"와 같은 뜻으로 봄. 3회차(규제)·2회차(비규제) 이후 접수 방식은 법령에서 사업주체가 정한다는 것 외에 확인 못 함.
5. **임의공급 신청 자격 세부**: 사업주체가 공고로 정함 — 일반 기준 없음(R1). 선착순(제28조제10항)과 청약홈 "임의공급" 접수의 관계는 법령 조문에서 직접 확인 못 함.
6. **제4조제1항제1호 괄호(부부 각각 신청 예외)의 신설일** — 조문 끝 개정일 목록만 있어 언제 생겼는지 확인 못 함(최종 개정 2026.6.15.로만 표기). 예외에서 빠지는 「공공주택 특별법 시행령」 제2조제1항 각 호 주택 종류는 이번에 열어 보지 않음 — 글에는 "공공주택 일부 유형은 예외에서 빠져 공고문 확인"으로만.
7. **민영주택 부부 각각 청약**: 법령은 민영주택을 "1인 1주택"으로 공급(제4조제1항제2호)하고 제55조의2를 두는 것까지만 확인. 민영 비규제 일반공급에 부부가 둘 다 당첨됐을 때 처리(제55조의2 각 호에 해당하지 않는 경우)는 조문에 직접 규정이 없음 — 글에서 결론 내지 않음.
8. **현재 투기과열지구·조정대상지역 목록** — 이번 문서 범위 밖(beginner 5-3 참조).
9. **경쟁률 "-" 표시 의미**: R7 화면에서 1순위 해당지역 마감 후 기타지역 칸이 "-"로 표시되는 것만 확인. 공식 정의 문장은 확인 못 함 — 글에는 "해당지역에서 마감돼 기타지역 경쟁률을 따로 계산하지 않은 경우 '-'로 보여요"로 쓰지 않고 화면 사실만.
10. 국토교통부 보도자료·주택청약 FAQ(국토부 발간) 원문은 이번에 열어 보지 않음.

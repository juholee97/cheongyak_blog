## 확인 못 한 항목 / 출처 간 차이

1. **"계약면적"의 법령 정의** — 내려받은 법령 원문에서 용어 자체를 찾지 못함. 공고문마다 면적표 주석으로 확인해야 함(이번에 공고문 PDF는 열지 않음).
2. **주택형 알파벳(A·B…)의 공식 뜻** — 청약홈은 "type이 있는 경우 type포함"이라고만 표기. "평면 구조가 다르다"는 설명은 공식 출처에서 확인 못 함 → 글에는 "타입마다 전용면적 소수점·금액이 다르고, 평면은 견본주택 평면도·공고문에서 확인"으로만 씀.
3. **청약홈 로그인 뒤 화면**(주택소유확인·청약제한사항확인·청약자격진단·세대구성원 등록/동의) — 로그인하지 않아 결과 화면 구성·필요 동의 절차는 확인 못 함. 메뉴 존재와 FAQ 설명만 사용.
4. **종합저축 전환 기한 출처 간 차이** — N8(상품기준일 2025.08.25 표기 페이지)·policy2 K3: 2027.9.30. / N10 FAQ: '26.9.30. — 글에는 2027.9.30. 사용.
5. **명의변경 기준일 표기 차이** — A9 "2000. 3. 27. 이후 가입" vs N9 "2000.03.26 후 가입"(같은 뜻으로 봄).

## 확인 못 한 항목 / 출처 간 차이

1. **신혼부부 특공 실제 고시 비율**: 규칙은 "민영 15%·국민 20%의 범위에서 국토부장관이 고시하는 비율" — 고시 원문의 비율 값은 확인 못 함(청약홈은 "15% 내", "20% 내"로만 표기).
2. **다자녀 특공 배점기준표** 세부 점수(청약홈 팝업) — 열어 보지 않음, 확인 못 함.
3. **생애최초 1인가구 면적 제한 표현 차이(출처 간 차이)**: 규칙은 "단독세대주나 세대주와 같은 세대별 주민등록표에 등재되어 있는 사람(세대원은 제외)"은 60㎡ 이하, 청약홈은 "직계존속과 함께 등재되지 않은 단독세대는 60㎡ 이하, 직계존속과 함께 등재된 1인가구는 전 주택형" — 글에는 "1인가구는 60㎡ 이하 제한이 있을 수 있어 공고문 확인"으로만.
4. **부동산가액 3억 3,100만원**: 청약홈 게시 금액. 법령은 "건강보험 재산등급 29등급 하한·상한 평균"으로만 정하고, 금액의 적용 연도는 확인 못 함.
5. **소득 금액표 연도**: 청약홈 게시는 2025년도 기준 — 공고 시점별 적용 연도는 공고문 확인.
6. **청년 특별공급** 비율·선정 기준(「공공주택 특별법 시행규칙」) — 조사 범위 밖.
7. **특공 접수 순서**: 규칙에 "특별공급 → 1순위 → 2순위" 접수일 순서를 직접 정한 조문은 찾지 못함. 청약홈 공고 상세(A11) 일정 표기 순서와 제25조제7항·제8항(특공 후 남은 주택을 일반공급)으로만 확인.
8. **LTV 정식 한글 명칭**: 공식 출처에서 명칭 정의 문장은 확인 못 함 — 주택도시기금 대출금액 산식(loans S1)으로만 설명.
9. **추가선택품목 규칙(B1)의 적용 범위**: 목적 조문상 분양가상한제 적용주택 기준. 그 밖 주택의 옵션 방식은 확인 못 함.
10. **주택법 일부 조문의 시행일 표기**: 국가법령정보센터 현행본(시행 2026.9.8.)에 제2조는 [시행일: 2027. 3. 9.], 제57조는 [시행일: 2027. 9. 9.] 표기가 붙어 있음(정의 내용 자체는 이번 글 범위에서 변화 없다고 봤지만 개정 내용은 확인 못 함).
11. 정책브리핑·국토부 보도자료 원문은 이번에 새로 열어 보지 않음(법령·청약홈 원문으로 확인).
12. points.md·loans.md의 "확인 못 함" 항목(시행일 등)은 그대로 승계.

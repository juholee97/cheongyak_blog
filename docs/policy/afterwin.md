## 확인 못 한 항목 / 출처 간 차이

1. **민간택지 분양가상한제 적용 지역 현재 지정 현황** — 국토교통부 지정 공고 원문을 이번에 찾지 못함(10.15 대책 K6에는 분상제 지역 변경 내용 없음). 글에는 "공고문 특이사항의 분양가상한제 표시로 확인"으로만.
2. **주택법 제57조제2항(적용 제외) 2026.2.3.·2026.9.8. 개정분의 호별 시행일** — API 제공본(시행 2027.3.9.)에만 있어 지금 시행 중인 호가 무엇인지 확인 못 함. 글에는 오래된 주요 예(도시형 생활주택·경제자유구역·관광특구 초고층·일부 정비사업)만.
3. **분양가 100% 이상 수도권 분상제 주택의 거주의무** — 시행령에 해당 구간이 없음을 확인했을 뿐, 국토부 해석 문서는 보지 않음. 글에는 "시행령 구간은 80% 미만·80~100% 미만 두 가지"로만.
4. **계약 포기 시 위약금·계약금 처리** — 법령은 "해약조건을 계약서에 넣어야 한다"까지만. 위약금 비율은 단지별 계약서 — 확인 못 함(글에 숫자 안 씀).
5. **당첨 통장 처리(해지·재가입 절차)** — 규칙 제7조는 "같은 통장으로 다른 주택 신청 불가"만 정함. 당첨 통장을 해지해야 하는지, 새 통장의 가입기간 인정 등 은행 절차는 확인 못 함.
6. **출처 간 차이 — 전매 허용 사유**: 청약홈 FAQ(A9b)는 "사업주체의 동의", 사유 7가지로 안내. 현행 시행령 제73조제4항은 "한국토지주택공사의 동의", 사유 8가지(실직·파산·신용불량 추가, 2024.6.18. 이후 개정분) → 글은 시행령 기준.
7. **출처 간 차이 — 서류 보관 기간**: 공고문 예시(A11)는 "입주자로 선정되지 않은 경우 6개월, 선정된 경우 10년 보관"으로 적었으나 규칙 제52조제4항은 "5년(재당첨제한 10년이면 10년)" — 글에는 쓰지 않음.
8. **공고문 PDF 숫자 깨짐**: A11 PDF 텍스트 추출 시 일부 숫자(거래신고 대상 금액 등)가 깨져 읽히지 않음 → 그 숫자는 쓰지 않음(거래신고 기한 30일은 D1 원문으로 확인).
9. **특별공급 미계약 시 "1회 사용" 간주**: 규칙 제55조는 "한 차례에 한정"만 정함. "동·호수 배정 후 미계약도 1회로 간주"는 공고문 예시(A11) 문구 — 다른 단지 공고문도 같은지는 확인 못 함.
10. **실거주 의무 유예 대상 판단**: 부칙 제2조·제3조로 "사용검사 시점" 기준임을 확인. 개별 단지가 어느 쪽인지는 사업주체·LH 확인 필요.

## 확인 못 한 항목 / 출처 간 차이

1. 청년 주택드림 청약통장의 월 납입 하한(기금 페이지에 별도 표기 없음), 현재 금리표의 최초 적용 시작일.
2. 청년 주택드림 디딤돌 대출의 실제 출시일(기금 페이지에 표기 없음). 출시 당시 안내(분양대금 80%·2%대)와 현재 페이지 값(LTV 70~80%, 2.4%~4.15%)은 다름 — 현재 페이지 값만 사용.
3. 버팀목 각 상품의 소득·보증금·금리 기준 최초 적용 시작일. 일반 버팀목 호당한도(1.2억원/8천만원)가 6.27 대책 때 바뀌었는지 여부.
4. 생애최초 취득세 감면의 전입(상시 거주 시작) 기한 — 현행 제36조의3에서 확인 못 함. 2026 개편안(오피스텔·40세 미만 300만원)은 국회 통과 전이라 미확정.
5. 청약통장 소득공제 대상에 배우자를 포함한 개정의 적용 시작 과세연도. 종전 통장 전환 즉시 3.1% 적용의 시행일.
6. 주택청약종합저축 상품 페이지의 "상품기준일 2023.08.30" 표기와 페이지 금리(2.3%~3.1%, 2024-09-23 인상분)가 시점상 맞지 않음 — 금리는 정책브리핑(K2)으로 교차 확인.

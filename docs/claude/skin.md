# 티스토리 스킨·홈·달력 화면 (`skin/`, `preview/`)

스킨, 홈, 달력 페이지, 내 청약 할 일을 고칠 때 읽는다. 적용 방법은 `tistory-automation.md`의 「스킨 적용」. 괄호 안 날짜로 `history.md` 검색.

## 고칠 때 규칙
- 스킨 수정 후엔 `preview.bat check`와 브라우저 미리보기(PC·휴대폰 폭) 확인. 티스토리 치환자는 `tistory.github.io/document-tistory-skin` 문서에 있는 것만 쓰고, 새로 쓰면 `preview/serve.mjs`의 KNOWN에도 추가한다.
- **디자인 변경은 미리보기·영상으로 먼저 승인받고 적용**(2026-11-10). 도구: `preview/unslop/build.mjs`(로컬 전·후 + 과정 영상), `live.mjs`(실제 블로그에 브라우저에서만 얹어 찍기), 규칙 원본 `steps.mjs`. 결과물 `preview/unslop/out/`은 커밋 안 함.
- 다듬기 기준(2026-11-10): 간격 4px 단위, 작은 글자 자간 0, 모서리 판 12·버튼 8~10·태그 6(알약 없음), 그림자 옅게. 글씨 굵기는 그대로(600·700 안 모두 사용자 거절).
- 홈 요약(#hero)·전체 달력(#cal) 틀은 `<script type="text/template">`로 감싸 홈·청약일정 화면에서만 꺼낸다 — 글 페이지에 같은 빈 틀이 반복되면 검색 수집·애드센스 심사에 불리(2026-10-26).
- 로고·기관 로고는 `style.css`에 data URI로(파일 업로드는 `apply_skin` 대조가 실패).
- 스킨 `<head>`에 GA4 gtag, 스킨 끝에 네이버 애널리틱스(wcslog.js). 값은 `seo-analytics.md`.

## 화면 구성
- 상단 메뉴(기록에 나온 것): 「청약달력」(이름만 바꿈, 연결은 `/category/청약일정` 그대로), 「단지 분석」(우리의 집 홈 https://auleezip.com/ , 새 창), 「대출·정책」, 「방명록」 다음에 「개인정보처리방침」. 메뉴는 `/manage/design/menu.json`.
- 홈: 이번 주 요약(월~일 접수·발표·계약 수, 시·도 타일 지도) + 「이번 주 남은 접수」 기관 블록 4개(청약홈·LH 청약플러스·SH·서울시 청년안심주택 — 로고, 남은 접수 n곳, 「자세히 보기 →」) + 글 목록. 끝난 접수는 뺀다. 출처는 공고 id 앞머리(lh-·sh-·youth-)로 구분.
- 홈 「전체 청약 달력 보기」에 마우스를 올리면 지도 칸이 뒤집히며 이번 달 달력(마우스 있는 화면만, Windows 시각 효과 끔에서도 재생 — 끝없이 도는 화살표만 그 설정을 따름). 날짜 칸을 누르면 달력 페이지가 `#d=YYYY-MM-DD`로 열린다. 점검 `preview/unslop/flip.mjs`.
- 달력 페이지(body `cal-page`): 지역 필터(서울 25개 구·경기 31개 시·군, PC는 접기/펼치기), 「주택 종류」× 「공고 종류」 두 줄 필터(둘 다 켜진 공고만, 저장값 `cheongyak-house-off`·`cheongyak-notice-off`), 단계 체크(「마감」·「계약」은 처음에 꺼 둠 — 달력은 청약하려는 사람이 본다), 아래 기관별 「이번 주 남은 접수」 목록(`[data-srclist]`, `#src-기관`, 위 필터를 따르는 토글 「달력 필터 적용」 — localStorage `cheongyak-srclist-filter`, 4곳 이상이면 268px 안에서 스크롤). 목록 줄을 누르면 달력 칸과 같은 상세 창(`data-act="open"`, 기관 사이트로 바로 나가지 않음, 2026-11-16).
- 집 종류는 자료에 없어 공고 종류로 정한다(`calendar.js` HOUSE_APT). 청년안심주택은 건축물대장 기준(`it.house`).
- 바탕: PC는 전체 흰색(판은 테두리), 휴대폰은 날짜별 카드 아래만 회색.
- 달력 상세 창: 아래 버튼 줄 첫 칸은 공고 원문(청약홈 공고는 「청약홈 게시글 보기」, 2026-11-16), 버튼 글자는 한 줄 — 같은 너비로 안 들어가면 긴 버튼만 넓히고, 그래도 안 되면 다음 줄로(휴대폰은 셋째 칸이 늘 한 줄 전체, 2026-11-16). 셋째 칸에 우리의 집 글 링크(검정 바탕·금색 글자 「이 단지 심층 분석」/「주변 시세 비교」, `crawler/auleezip_links.json`). PC는 창 오른쪽 「자격 확인」 리모콘(계산기 /75 새 탭, 청약홈 공고는 `#n=공고번호`). 점검 `preview/unslop/modal3.mjs`.
- 카테고리 「청약가이드」·「대출·정책」 첫 쪽 위 「먼저 볼 핵심 글」 3편 고정 — 글 번호는 `skin.html`의 `tpl-core-guide`·`tpl-core-loan`에서 바꾸고 스킨 재적용. 점검 `preview/unslop/core.mjs`.
- 글 목록: 홈에서 목록(s_list) 숨김, 카테고리·태그·검색에서는 `.rep-grid` 카드 숨김(같은 글 두 번 방지). 썸네일 1200:630.
- 사이드바와 한 줄일 때(폭 948px 이상) `.blog-main` max-width calc(100% - 300px) — 본문 위 광고가 사이드바를 덮던 문제(2026-10-27).

## 내 청약 할 일 (`skin/images/todo.js`, 2026-11-09)
- 달력 상세 창 접힘 칸: 공고 + 신청 유형 → 날짜순 할 일 → 카톡으로 나에게 보내기(개인 링크 `#todo=공고&p=유형`)·달력 파일(.ics)·목록 복사. 서버·로그인·저장 없음.
- **광고 시청 조건을 달지 않는다**(애드센스는 보상형 외 광고 시청 요구 금지).
- 공고 날짜는 자료 그대로, 준비 날짜(D-7·3·1)는 「권장 시점」으로 구분. 09:00~17:30·청약홈 메뉴 안내는 청약홈 APT 메뉴 공고만(`viaApplyhome`). 1·2순위 날짜는 해당지역 칸뿐이라 제목에 「(해당지역)」.
- 함께 볼 글은 공고 종류별 최대 3개(`links()`, utm_source=todo). 부적격·계약 포기 글은 무순위·임의공급에 안 붙인다.
- 점검 `preview/todo.check.mjs`. 내려받기 수는 GA4 `todo_download`.
